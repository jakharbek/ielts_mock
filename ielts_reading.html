IELTS Reading Test — Practice Simulator

Тренажёр компьютерного IELTS Reading Test: таймер по центру, Settings (шрифт/фон) и Hide справа, подсветка/заметки по правому клику, Review и Previous/Next снизу. В Settings есть блок 🔀 AI Integration — можно выбрать провайдера: свой ключ OpenRouter (любая модель — Claude, GPT, Gemini, DeepSeek и т.д.) или локальный claude-server на этой машине (использует твой логин Claude Code, без API-ключа). Одной кнопкой генерируется совершенно новый тест (другие тексты и вопросы), плюс сохранение/импорт теста в JSON.

You should spend about 60 minutes on this test, which has 3 parts and 40 questions. Read the instructions for each part carefully. Answer all questions. You can change your answers at any time before submitting.

  • Part 1 — Questions 1–13
  • Part 2 — Questions 14–27
  • Part 3 — Questions 28–40

Select text in the passage and right-click to highlight it or add a note. Use the flag button to mark questions for review. Use Review in the bottom-left to see your progress, and Settings in the top-right to adjust text size, background colour, and the AI integration.

🔀 AI Integration

Generate a completely new IELTS Reading test — new passages, new questions, new answer key — using either your own OpenRouter API key (cloud, any model) or a local claude-server running on this machine (uses your Claude Code login, no API key). Pick a provider below.

1 · AI Provider

2 · OpenRouter API Key

How to get an OpenRouter API key
  1. Go to openrouter.ai/keys and sign in (Google, GitHub or email).
  2. Click Create Key, give it a name (e.g. "IELTS practice app"), and copy it — it starts with sk-or-v1-....
  3. Add credits under openrouter.ai/credits (pay-as-you-go) — or pick a model whose name ends in :free to try it without credits.
  4. Paste the key below and click Save.
Model

Type the exact model slug (provider/model-name — browse them all at openrouter.ai/models). The model must support tool calling for generation to work — most current frontier models do.

Effort

Complex generation prompts can make the model think for several minutes at the default effort before any text appears (this is normal, not frozen — watch the "thinking" counter below). Lower effort trades some depth of reasoning for a much faster response; in testing, "Low" generated a full test in ~1 minute instead of ~6.

3 · Audio Narration Engine

Choose how the right-click "🔊 Listen" feature reads a passage selection aloud. The browser engine is free and needs no key; ElevenLabs sounds more natural but requires your own API key and uses your ElevenLabs quota. These settings are shared with the IELTS Listening trainer — set once, used on both pages.

Narration Speed

Applies to both narration engines and takes effect immediately on the next "Listen" click.

Voice ID

Advanced Voice Settings
Stability 0.50

Lower stability sounds more expressive and varied but less consistent; higher stability sounds flatter but more uniform. The defaults (0.50 / 0.85 / Speaker Boost on) match ielts_listening.html's tuning. Click Save below to apply changes.

4 · Generate a New Test

Stateless: this instantly replaces the current test (new topics, new passages, new questions and answers) and resets the timer. Nothing is saved automatically — use Save below if you want to keep it.

Your preferences (optional)

Tell the AI what you want this test to be about — a subject area (e.g. IT, healthcare, climate), a region/setting, a tone, anything. Left blank, the AI picks freely. Your preference is remembered for next time.

5 · Save / Import

Save the current test (default, generated, or imported) to a JSON file, or load a previously saved test.
