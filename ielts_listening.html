IELTS Listening Test — Practice Simulator

Computer-based IELTS Listening Test trainer: 4 sections, 40 questions, one overall timer (~40 minutes) for listening and checking answers. Audio is played right in the browser — via the built-in speechSynthesis engine (free, no key required) or, optionally, through ElevenLabs (your own API key and voice IDs). Both AI providers (OpenRouter / local claude-server) and the ElevenLabs voice are configured under Settings → 🔀 AI Integration. The same panel has a Strict Exam Mode toggle — just like the real exam, each section's audio plays once with no pause/rewind; turn it off to practice with pausing and replay.

You should spend about 40 minutes on this test, which has 4 sections and 40 questions. Each section is heard once only in Strict Exam Mode. Answer all questions — you can change your answers at any time before submitting.

  • Section 1 — Questions 1–10 (everyday conversation)
  • Section 2 — Questions 11–20 (social-context monologue)
  • Section 3 — Questions 21–30 (educational discussion)
  • Section 4 — Questions 31–40 (academic lecture)

Use the Play Section Audio button in each section to hear its recording, then answer the questions below it. Use the flag button to mark questions for review. Use Review in the bottom-left to see your progress, and Settings in the top-right to adjust text size, background colour, the AI integration and the audio engine.

How to get an OpenRouter API key
  1. Go to openrouter.ai/keys and sign in (Google, GitHub or email).
  2. Click Create Key, give it a name (e.g. "IELTS practice app"), and copy it — it starts with sk-or-v1-....
  3. Add credits under openrouter.ai/credits (pay-as-you-go) — or pick a model whose name ends in :free to try it without credits.
  4. Paste the key below and click Save.
Model

Type the exact model slug (provider/model-name — browse them all at openrouter.ai/models). The model must support tool calling for generation to work — most current frontier models do.

3 · Audio Narration Engine

Choose how section transcripts are read aloud. The browser engine is free and needs no key; ElevenLabs sounds more natural but requires your own API key and uses your ElevenLabs quota.

Narration Speed

Applies to both narration engines and takes effect immediately, including sections whose audio is already loaded — real IELTS recordings run at a natural, unhurried pace, so Normal is the closest match; slow it down while you're still building listening speed, or speed it up once you're comfortable.

Male Voice ID
Female Voice ID

Defaults are George (male) and Charlotte (female) — clear, articulate British voices matching the register of real IELTS Listening recordings, rather than the generic American voices most apps default to. If a section has two speakers of the same gender (e.g. Section 3's two male speakers), a second built-in British voice (Daniel / Lily) is used automatically so they don't sound identical. Click Browse to search ElevenLabs' full voice library and preview voices right here, or paste any voice ID directly to override the primary voice.

Advanced Voice Settings
Stability 0.50
Similarity Boost 0.85

Lower stability sounds more expressive and varied but less consistent line-to-line; higher stability sounds flatter but more uniform. The defaults (0.50 / 0.85 / Speaker Boost on) are tuned to match the clear, consistent register of real IELTS recordings — most candidates won't need to change these. Click Save below to apply changes.

4 · Generate a New Test

Stateless: this instantly replaces the current test (new topics, new transcripts, new questions and answers) and resets the timer and all audio. Nothing is saved automatically — use Save below if you want to keep it.

Your preferences (optional)

Tell the AI what you want this test to be about — a subject area (e.g. IT, healthcare, travel), a setting, a tone, anything. Left blank, the AI picks freely. Your preference is remembered for next time.
