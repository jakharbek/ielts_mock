IELTS · ACADEMIC WRITING

IELTS Writing Test — Practice Simulator

Тренажёр компьютерного IELTS Writing Test: Task 1 (отчёт по диаграмме, ≥150 слов, ~20 мин) и Task 2 (эссе, ≥250 слов, ~40 мин), общий таймер 60 минут. После сдачи работу оценивает ИИ-экзаменатор — по всем 4 официальным критериям (Task Achievement/Response, Coherence & Cohesion, Lexical Resource, Grammatical Range & Accuracy), с баллом по каждому критерию, итоговым Band Score и конкретными исправлениями по тексту. В Settings → AI Integration можно выбрать провайдера: свой ключ OpenRouter (любая модель — Claude, GPT, Gemini, DeepSeek и т.д.) или локальный claude-server на этой машине (без API-ключа, использует твой логин Claude Code).

You should spend about 20 minutes on Task 1 (write at least 150 words) and about 40 minutes on Task 2 (write at least 250 words) — 60 minutes total. Task 2 contributes twice as much as Task 1 to your overall Writing band.

  • Task 1 — describe/summarise visual data (chart, graph or diagram)
  • Task 2 — write a discursive essay responding to a point of view, argument or problem

Use Settings in the top-right to adjust text size, background colour, and the AI integration. When you submit, your writing is graded automatically by the AI examiner using the provider and model you selected.

🔀 AI Integration

Uses either your own OpenRouter API key (cloud, any model) or a local claude-server running on this machine (uses your Claude Code login, no API key) to (1) generate brand-new Writing task sets and (2) grade your submitted writing as an AI examiner. Pick a provider below.

How to get an OpenRouter API key
  1. Go to openrouter.ai/keys and sign in (Google, GitHub or email).
  2. Click Create Key, give it a name (e.g. "IELTS practice app"), and copy it — it starts with sk-or-v1-....
  3. Add credits under openrouter.ai/credits (pay-as-you-go) — or pick a model whose name ends in :free to try it without credits.
  4. Paste the key below and click Save.
Model

Type the exact model slug (provider/model-name — browse them all at openrouter.ai/models). The model must support tool calling for generation and grading to work — most current frontier models do. This key/model is shared with the IELTS Reading practice app in this browser.
