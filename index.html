AI-интеграция

Подключи ИИ — генерируй тесты и получай подсказки

В каждом тренажёре (Reading, Writing, Listening, Speaking) в Settings → 🔀 AI Integration можно подключить нейросеть, чтобы генерировать совершенно новые тесты «по кнопке», получать подсказки по вопросам и разбор ответов. Провайдера выбираешь сам — вариант из облака или полностью локальный, на твоей подписке.

🔀

OpenRouter

Облако

Свой API-ключ openrouter.ai — выбираешь любую модель (Claude, GPT, Gemini, DeepSeek и др.) под конкретную задачу.

  • Оплата pay-as-you-go, либо модели с суффиксом :free
  • Нужна модель с поддержкой tool calling
  • Работает из любого браузера, без установки
🖥️

Claude Server

Локально · без ключа

Локальный сервер из claude-server.zip — прокси к Claude Code CLI, использует твою подписку Claude (claude login). Никакой API-ключ не нужен и не расходуется.

  • OpenAI-совместимый API на 127.0.0.1:8137
  • Генерация тестов на модели Opus / Sonnet / Haiku
  • Данные не уходят к третьим сервисам — всё на твоей машине
Скачать claude-server.zip
🔊

ElevenLabs

Озвучка

Реалистичное озвучивание текста в Reading/Listening — правый клик → «Listen» читает вслух выделенный фрагмент голосом по твоему выбору из библиотеки голосов.

  • Свой API-ключ ElevenLabs, настройки общие для Reading и Listening
  • Поиск и предпрослушивание голосов прямо в настройках
  • Без ключа доступен голос браузера — бесплатно, но менее живой

⚙️ Быстрый старт с Claude Server (рекомендуется)

1

Скачай и распакуй архив сервера, затем авторизуй CLI один раз:

claude-server.zip 
# требуется Node.js 18+
npm install -g @anthropic-ai/claude-code
claude login
2

Запусти локальный сервер — он слушает только 127.0.0.1, наружу не торчит:

cd claude-server
node server.js
3

В любом тренажёре открой Settings → 🔀 AI Integration, выбери Claude Server (local) и жми «Generate New Test» — ИИ соберёт новый вариант теста целиком.

💡 Что выбрать: если есть подписка Claude (Max/Pro) — бери Claude Server, это бесплатно и приватно поверх уже оплаченной подписки. Нужна конкретная модель не от Anthropic или работа без установки Node.js — используй OpenRouter. Для живой озвучки текста в Reading/Listening дополнительно подключи ElevenLabs. Все настройки хранятся локально в браузере (localStorage) и общие для всех четырёх тренажёров.
